Web application built by a team of 5 that allows users to select and compare up to 4 cars simultaneously, featuring side-by-side specification comparisons and interactive data visualisations.

Pulls vehicle data from a structured database and renders dynamic comparison charts for metrics like horsepower, fuel efficiency, price, dimensions, and more.

Key features:

- Search and select vehicles from a comprehensive database
- Compare up to 4 cars side-by-side
- Interactive graphs for visual data comparison
- Detailed specification breakdowns

Built with a Django REST backend and React frontend, developed using Agile methodology with Git/GitHub for version control and team collaboration.
